# 総合無料Webツール＋便利グッズサイト　現状まとめ（2026年10月19日）

## 1. 目指しているもの
単なるツール集やアフィリエイトサイトではなく、日常の困りごとを解決するポータルサイト。

- **無料Webツール**（集客の柱）：計算・文章変換・画像・PDF・日付など、100機能以上
- **便利グッズ図鑑**（収益の柱）：仕事・スマホ・家事・旅行などのアイテムの選び方と紹介
- **悩み別おすすめ**：「デスクを片付けたい」などの悩みから、ツールや商品を探せる
- **使い方・比較ガイド**：ツールの使い方、商品の比較、選び方

本番サイトの仮称は「ツールひろば」。名前は設定ファイルで管理し、後から変えられるようにする。

## 2. 今できているもの（試作版）
Claude（AI）上で動く1ページの試作サイト「道具箱」。ファイル名は `dougubako.html` で、ブラウザで開けば動く。

### 画面の構成
- **総合トップ**：検索窓、4つの入口（無料Webツール／便利グッズ／悩み別に探す／特集・比較ガイド）、人気ツール、季節の特集、新着ガイド
- **無料Webツール**：11分類・112種類（下の一覧）
- **便利グッズ**：5ジャンル・20品目。品目ごとに「選び方のポイント」と「比べるときに見る仕様」を掲載
  - 実在の商品はまだ載せていない。PR表記付きの商品カードの見本だけある。
- **悩み別**：9テーマ。それぞれ、解決のヒント・使えるツール・関連グッズ・関連ガイドにつながる。
- **特集・比較ガイド**：7本。HEIC→JPGの方法、PDFを軽くする方法、割り勘のコツ、充電器の選び方、CSVの文字化け、デスクの片付け、他サイトとの違い。
- **共通機能**
  - ツール・グッズ・悩み・ガイドをまとめて探せる検索
  - パンくずリストと、ツールページの関連情報（関連があるものだけ）
  - 最近使ったツールの表示
  - スマホでは画面下のタブメニュー

### 特徴
- 登録不要で、回数の制限もない。
- OCR以外は、ファイルも文字もサーバーに送らず、ブラウザの中だけで処理する。
- 日本向けの機能が多い（Shift_JISのCSV、和暦、日本の祝日、電子印鑑、原稿用紙、消費税の端数処理、坪・畳）。

## 3. 試作版の制約（本番化が必要な理由）
- 1ページのアプリなので、ツールごとのURLがなく、検索エンジンからの流入を取りにくい。
- 広告タグやアフィリエイトのリンク・スクリプトを置けない。
- OCRは、試作環境ではClaudeのAIを使っているため、本番では別の方法が必要になる。
- ファイルの保存も、試作環境独自の仕組みを使っている。

## 4. 本番サイトの計画（実装設計書にもとづく）
- **技術**：Next.js（App Router）＋TypeScript＋Tailwind CSS。Vercelなどにデプロイ。
- **データの持ち方**：ツール・商品・記事・カテゴリをデータファイルで管理し、画面とは分ける。
  - 商品データには、出典・価格の確認日・確認状況・公開状態を持たせる。
- **URL**

  | ページ | URL |
  |---|---|
  | ツール | `/tools/[slug]` |
  | ツールのカテゴリ | `/tools/category/[slug]` |
  | 商品 | `/goods/items/[slug]` |
  | 比較ガイド | `/guides/[slug]` |
  | 悩み別ガイド | `/solutions/[slug]` |
  | 運営者情報・広告表記・プライバシー・お問い合わせ | `/about`、`/disclosure`、`/privacy`、`/contact` |

- **運用ルール**
  - AIが書いた記事は自動で公開しない（確認状態を管理する）。
  - 未確認の機能や商品は、一覧に出さない。
- **12週間の計画**
  - 1〜2週：基盤
  - 3〜4週：20〜30機能で初期公開
  - 5〜8週：60〜80機能
  - 9〜12週：100機能以上
- **進み具合**：Node.jsのインストールが完了した。次は、プロジェクトの土台（設計、データ型、共通レイアウト、トップ・一覧ページ）を作る。試作版のツールの計算部分は、TypeScriptにほぼそのまま移せる。
