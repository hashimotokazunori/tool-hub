# 便利グッズ 商品候補（下書き・要確認）

調査日：2026-10-19

便利グッズ5ジャンルについて、メーカー公式ページ（またはメーカー直営ストア）で実在と仕様を確認できた商品を2つずつ、計10商品挙げています。

- 下のオブジェクトは `lib/types.ts` の `Product` 型に合わせた下書きです。すべて `status: "draft"`、`reviewStatus: "pending"` です。
- `specifications` には、公式ページで確認できた値だけを入れています。公式ページに載っていない項目（耐荷重やPSE表記など）は入れず、各商品の「要確認事項」に書いています。
- `price` は、公式ページ（メーカー直営ストアを含む）に**税込価格**が出ていたものだけに入れています。「オープン価格」「税別のみ」「どのサイズの価格か分からない」ものは入れていません。
- アフィリエイトリンクと画像URLは入れていません（提携先と画像の使用条件をまだ確認していないため）。
- `sourceUrls` には、実際に開いて仕様を確認したページだけを入れています。
