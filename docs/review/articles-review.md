## 0. 最重要（公開前に必ず直すもの）

1. **飛行機のモバイルバッテリールールが古い（2026年4月24日に変更済み）**
   国土交通省は2026年4月14日に、新ルールを2026年4月24日から適用すると発表した。
   - 機内に持ち込めるモバイルバッテリーは**1人2個まで（160Wh以下に限る）**。100Wh以下のものも2個の枠に入る。
   - **機内でモバイルバッテリーを充電しない**。
   - **機内でモバイルバッテリーから他の電子機器を充電しない**。
   - 2025年7月8日からは、座席上の収納棚に入れず、座席ポケットなど手元に置くよう求められている。

   `choose-charger-mobile-battery.md` の「100Whを超えるものは個数の制限があります」と、`buying-guides.ts` gadgets-06 の「100Wh超は個数制限あり」は、2026年4月以降のルールとしては不正確。
2. **`articles.ts` の既存 `sources` が不適切**
   タイトルは「モバイルバッテリーの電気用品安全法上の取扱いについて」だが、URL は電気用品安全法のトップ（`/denan/`）を指している。このURLは当方の環境では 403 となり、中身を確認できなかった。モバイルバッテリー専用のFAQ（下記）に差し替えることを推奨。
3. **CSV記事の「はしご高」の例は不正確**
   「髙」（U+9AD9）は、JIS X 0208 ベースの Shift_JIS にはない。ただし Windows の Shift_JIS（CP932）には収録されている（0xFBFC／0xEEE0）。Windows・Excel向けの説明としては、例が適切でない。
4. **メール添付「10MB前後」の言い切りは根拠不足**
   Gmail（個人）は25MB、Outlook のインターネットメールは既定20MB、Exchange（会社のメール）は既定10MB。
